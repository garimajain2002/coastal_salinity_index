# CoSal: A remote sensing and machine learning framework for mapping coastal soil salinity trends around aquaculture in South Asia

This is a repository of R scripts and associated data for deriving a remote-sensing based index for salinity in coastal India

Please cite the data with the following citation:

Garima Jain, Wenxin Yang, Showmitra Kumar Sarkar, Amy E Frazier & Dylan S Connor. CoSal: A remote sensing and machine learning framework for mapping coastal soil salinity trends around aquaculture in South Asia, 25 March 2025, PREPRINT (Version 1) available at Research Square [https://doi.org/10.21203/rs.3.rs-6173117/v1]
